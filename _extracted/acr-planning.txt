Project Overview
 Project Description:
Ancient Civilization Reconstructor is a website where users can learn about ancient civilizations through pictures and digital reconstructions. Users can choose civilizations like Ancient Egypt, Rome, or the Maya and explore their buildings and environments.
The website will also have a feature where scientists can take a picture of a broken ancient piece and upload it to the app. The AI will use the picture and reference pictures to estimate how the complete piece may have looked and create a new picture. Since we are students, we will use pictures from Google and other sources as references for the project, and AI will create the estimated reconstruction.

Project Objectives:
Create an interactive website about ancient civilizations.
Allow users to select different civilizations.
Display reconstructed historical environments.
Provide educational information about each civilization.
Use technology and AI to improve learning experiences.
System Design
System Architecture / Design:
The user accesses the website and chooses a civilization. The system loads the related reconstruction, images, and historical information. Users can navigate through different sections to learn more about the civilization.
