G11 Term 3 – Project Overview

The CAI Capstone Project gives you the opportunity to apply the skills and knowledge you have learned at ATS to solve a real-world problem using AI technologies. The system analyzes crisis-related information, evaluates its credibility, identifies potential risks, and provides structured safety recommendations. It aims to reduce the spread and impact of misinformation while helping users make informed and safe decisions during emergencies such as armed conflicts, natural disasters, and public health crises. Project Objectives: • Develop a mobile application that analyzes crisis-related information using artificial intelligence • Detect misinformation and evaluate the credibility of information sources • Classify crisis situations into different risk levels (Low, Medium, High) • Provide clear and easy-to-understand safety recommendations • Create a fast and user-friendly interface suitable for emergency situations • Improve public awareness and support better decision-making during crises  2. System Design System Architecture / Design: The SANAD system follows a mobile client-server architecture. Users interact with the application through a mobile interface, while the backend processes crisis-related information, performs AI analysis, and generates safety recommendations. The architecture includes: Mobile Application (Client Side): User interface where users enter information and receive safety recommendations. Backend Server: Handles AI processing, credibility analysis, risk classification, and recommendation generation. Database: Stores user requests, crisis information, and system data. AI Processing Module: Performs Natural Language Processing (NLP), misinformation detection, and risk assessment. This design ensures efficient processing, secure data management, and accessibility across Android and iOS devices. Flowchart / Diagram:  Hardware / Software Architecture: Hardware: • Personal computer or laptop for development • Android device for testing • iPhone device for testing (optional) • Internet connection for cloud services and data access Software: • Flutter SDK • Python • Dart • Visual Studio Code • Android Studio • Xcode (optional) • Firebase • Git & GitHub • NLP and Machine Learning libraries  3. UI/UX Design Interface Description: The SANAD interface is designed to be simple, fast, and user-friendly, especially during emergency situations where quick decision-making is important. Main features include: • A welcome screen displaying the question: "What type of emergency are you facing?" • A text input area for entering crisis-related information • A "Check Safety" button to analyze the entered content • Three emergency category buttons: Conflict / War • Air raids • Missile alerts • Armed conflicts • Security threats Natural Disasters • Floods • Storms • Sandstorms • Earthquakes Health Crisis • Pandemics • Disease outbreaks • Lockdowns • Public health warnings • Skip General Mode button allowing users to continue without selecting a category The system focuses on: • Easy navigation • Fast interaction during emergencies • Clear categorization of crisis situations • Accessibility through large buttons and readable text • Color coding for risk levels and alerts • Stress reduction through a clean and organized interface Wireframes / Storyboard:   4. Algorithm / AI Model Design Algorithm Description: The SANAD system operates using a Natural Language Processing (NLP) and Machine Learning-based classification algorithm. First, the user enters crisis-related information into the application. The text is then preprocessed by removing unnecessary symbols, stop words, and formatting inconsistencies. After preprocessing, NLP techniques are applied to extract meaningful features such as keywords, phrases, and contextual patterns. These features are passed to a machine learning model trained to identify misinformation and assess information credibility. The system then analyzes the content to classify the level of risk as Low, Medium, or High based on detected threats, urgency indicators, and crisis-related patterns. Finally, a recommendation engine generates structured safety guidance and displays the results to the user, including credibility status, risk level, and recommended actions.
